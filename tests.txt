Лабораторная работа № 2. Тесты mathtool

Выполнять команды в PowerShell из каталога проекта.
Для ручного ввода каждое значение передаётся отдельной строкой.
В записи stdin символы \n обозначают переводы строк.
В тестах ручного solve stdout приведён без эха клавиатуры.
Текст argparse и переносы справки зафиксированы для Python 3.15.0.
Код возврата смотрите через $LASTEXITCODE сразу после команды.

========================================================================
01. Общая справка без аргументов
Команда: python mathtool.py
stdin: <пусто>
stdout:
usage: mathtool [-h] {solve,stats,series,integrate} ...

Расчёты над уравнениями и числовыми последовательностями.

positional arguments:
  {solve,stats,series,integrate}
    solve               решить линейное или квадратное уравнение
    stats               вычислить показатели последовательности
    series              просуммировать знакочередующийся ряд
    integrate           вычислить интеграл методом левых прямоугольников

options:
  -h, --help            show this help message and exit
stderr: <пусто>
Код возврата: 0
